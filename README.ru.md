# Island

[English](README.md) | **Русский**

Приложение для строки меню macOS на Swift и SwiftUI, вдохновлённое Dynamic Island.
Island обрамляет вырез камеры компактной стеклянной поверхностью, которая
раскрывается при наведении и показывает управление воспроизведением и таймеры.

**Текущая версия:** 0.3.0 · **Тег этапа:** `v0.3-multimodule`

## Возможности

- **Оболочка вокруг выреза:** состояния collapsed, compact и expanded, быстрое
  раскрытие при наведении, пружинные анимации и запасной режим «таблетки» для
  экранов без выреза.
- **Now Playing:** обложка и индикатор воспроизведения в compact; название,
  артист, обложка, прогресс и кнопки предыдущего трека, play/pause и следующего
  трека в expanded.
- **Несколько модулей:** compact показывает активный модуль с наивысшим
  приоритетом; точки в expanded переключают страницы. Таймер приоритетнее музыки.
- **Таймер и секундомер:** запуск, пауза, продолжение, сброс, пресеты на 1/5/10
  минут, своё время, короткая анимация завершения и один системный звуковой сигнал.
- **Общая дизайн-система:** системные шрифты, тёмное стекло, скруглённые обложки,
  акцентные цвета из обложки, общие компоненты и плавная бегущая строка для
  длинных названий.
- **Доступность и настройки:** Reduce Motion, выбор экрана, задержка раскрытия,
  видимость острова и необязательный запуск при входе в систему.

У Island нет иконки в Dock. Управление на острове сохраняет активным текущее
приложение; настройки и окно таймера открываются как обычные окна.

## Требования

- macOS 14 или новее — минимальная версия, указанная в пакете.
- Swift 6 и macOS SDK из Xcode или Command Line Tools.
- Проверенная конфигурация: MacBook Air 15″ M3 с вырезом, macOS 27.2.1.
  Другие версии macOS и устройства ещё требуют проверки.

Внешних Swift-пакетов нет. MediaRemote Adapter закреплён на конкретной ревизии
и собирается из исходников компилятором Apple clang; CMake не требуется.

## Сборка и запуск

Клонируйте репозиторий и соберите приложение локально:

```sh
git clone https://github.com/AndromedaOne1/Island.git
cd Island
./Scripts/build-app.sh         # Debug: build/Island.app
./Scripts/build-app.sh release # Release: build/Island.app
open -g build/Island.app
```

Либо используйте `./Scripts/run.sh` для сборки и запуска debug;
`./Scripts/run.sh release` собирает и запускает release.

Перед повторной сборкой завершите Island: обе конфигурации заменяют один и тот
же бандл. Скрипты проверяют метаданные и выполняют ad-hoc подпись.
Приложение рассчитано на локальную сборку и не проходит нотарификацию Apple.
Сборки, локальные скриншоты, логи и кэш исключены из Git.

Для запуска при входе используйте копию приложения по постоянному пути,
например `/Applications/Island.app`, и включите соответствующую настройку.
Скрипт сборки не устанавливает приложение и не меняет элементы входа в систему.

## Как пользоваться

1. Запустите воспроизведение или откройте **Timer & Stopwatch…** через иконку
   Island в строке меню и запустите таймер. Без активных модулей остров остаётся
   в collapsed.
2. Наведите курсор на вырез или его тонкую нижнюю границу. Задержка раскрытия
   по умолчанию — 0,05 секунды; после ухода курсора остров сворачивается через
   0,3 секунды.
3. Если активны музыка и таймер, compact показывает таймер. В expanded выбирайте
   страницу точками. При новом наведении открывается модуль с наивысшим приоритетом.
4. Значок часов слева от выреза в expanded открывает таймер, шестерёнка справа —
   настройки. Музыка и таймер на паузе остаются активными.
5. Завершённый таймер виден до нажатия **Done/Reset**. **Restart** запускает
   прежнюю длительность заново. Перед сменой режима Timer/Stopwatch нажмите Reset.

Своё время можно задать от 1 секунды до 24 часов. Время сна Mac учитывается;
сигнал завершения поступает после возобновления работы приложения. После выхода
из Island сессии не восстанавливаются.

Меню также содержит управление видимостью, настройки, выход и **Preview Compact
Layout** — диагностический просмотр compact без активного модуля. Если выбранный
экран отключён, временно используется автоматический выбор.

## Источники Now Playing и разрешения

Основной источник — закреплённый
[MediaRemote Adapter](https://github.com/ungive/mediaremote-adapter), работающий
в отдельном процессе helper. Он использует приватные API MediaRemote для чтения
выбранного системой плеера, включая поддерживаемые браузерные сессии.
Сам Island приватный фреймворк не загружает. При обнаруженном сбое helper
основной источник отключается и включается настроенный резерв Music/Spotify.

Резерв использует Apple Events и проверяет только разрешённые в настройках
плееры, которые уже запущены. Island объясняет назначение разрешения Automation
и запрашивает его только после нажатия **Allow Music Control…** или
**Allow Spotify Control…**. Обычное отсутствие воспроизведения не вызывает
переключения на резерв или запроса разрешения.

Если Automatic перестал показывать воспроизводимый трек, включите
**Use Music/Spotify backup** в настройках. **Retry Automatic** повторно запускает
основной источник. Отказанное разрешение можно изменить в настройках macOS:
System Settings → Privacy & Security → Automation. Другая подпись сборки
или установка приложения может потребовать повторного разрешения.

Метаданные воспроизведения читаются локально. Обложки резервного источника Spotify
могут загружаться по HTTPS. Подробности источников, разрешений, проверки лицензий
и чек-лист воспроизведения — в [Docs/NowPlaying.md](Docs/NowPlaying.md).

## Проверки

```sh
./Scripts/test.sh
./Scripts/test.sh release
```

Для версии 0.3.0 проходят **48 тестов Swift Testing в debug и release**.
Проверяются геометрия выреза, области нажатия, отмена hover, приоритеты и страницы
модулей, разбор данных и прогресс воспроизведения, резервный источник,
явное разрешение Automation, отмена helper, отсчёт таймера и секундомера
и завершение таймера.

Просмотрены реальные скриншоты compact с таймером, обеих expanded-страниц,
паузы, секундомера, завершения, idle/collapsed и Reduce Motion. Общий экран
таймера также проверен действиями в интерфейсе: пресеты, своё время, кнопки
и завершение.

Скрипт тестов находит Swift Testing в установленном toolchain.
Если стандартный планировщик сборки не работает, попробуйте:

```sh
ISLAND_TEST_BUILD_SYSTEM=native ./Scripts/test.sh
```

Для ручной проверки остаются управление Spotify и браузерными плеерами,
запрос Automation от финального приложения, слышимость сигнала, настоящий сон
и пробуждение Mac, fullscreen, Spaces, внешние экраны и запуск при входе.

## Структура проекта

```text
Sources/IslandApp/       App lifecycle, menu bar, windows, and shell views
Sources/IslandCore/      Geometry, panel, modules, design, playback, and timers
Tests/IslandCoreTests/   Swift Testing suite
Resources/              Bundle metadata and helper watchdog
ThirdParty/             Pinned adapter source and license notices
Scripts/                Build, bundle, sign, launch, and test
Docs/                   Architecture, design, and playback notes
```

Модули реализуют подтверждённый протокол `IslandModule`. Реестр управляет
включением и жизненным циклом, состояниями idle/active, приоритетом и отдельным
выбором страницы в expanded. Таймер использует непрерывные часы, а не системное
время. Подробности реализации и чек-листы:
[Docs/Architecture.md](Docs/Architecture.md) и [Docs/Design.md](Docs/Design.md).

## Известные ограничения

- Приватные API MediaRemote могут измениться после обновления macOS. Резерв
  Music/Spotify не поддерживает браузеры. Текущий основной источник не подходит
  для публикации в Mac App Store.
- macOS выбирает один плеер Now Playing. Метаданные и обложки могут задерживаться;
  команды зависят от поддержки плеера и наличия очереди воспроизведения.
- Отсутствие обложки, неизвестная длительность и отсутствие трека — нормальные
  состояния. Индикатор в compact отражает состояние воспроизведения, а не
  визуализирует звук.
- Сессии таймера не переживают выход из приложения. Сигналы поступают после
  возобновления работы, а не во время сна Mac или приостановки приложения.
